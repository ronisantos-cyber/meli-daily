Política de Privacidade

Meli Daily Assistant · Última atualização: 17/08/2026

Esta política descreve como o Meli Daily Assistant ("o aplicativo") trata os dados dos usuários, com destaque para os dados acessados por meio das APIs do Google. Ao usar o aplicativo e conectar sua conta Google, você concorda com os termos abaixo.

1. O que é o aplicativo

O Meli Daily Assistant é uma ferramenta de organização de rotina de equipe (anotações, tarefas/checklists, folgas, férias e afins), usada de forma opcional pelos colaboradores. A conexão com o Google é opcional e serve apenas para criar lembretes das suas tarefas na sua agenda.

2. Dados acessados na sua conta Google

Quando — e somente se — você tocar em "Conectar Google" e autorizar, o aplicativo utiliza a API do Google Calendar para:

  • Listar as suas agendas — apenas para que você escolha em qual agenda os lembretes serão criados;
  • Criar eventos na agenda que você escolher, correspondentes às tarefas que você cadastrar com horário (incluindo a repetição, quando a tarefa for recorrente).

O aplicativo não lê, não coleta e não armazena o conteúdo dos seus eventos existentes, nem qualquer outro dado da sua conta Google além do necessário para as ações acima.

3. Escopos solicitados e finalidade

  • .../auth/calendar.events — criar e gerenciar os eventos de lembrete das suas tarefas.
  • .../auth/calendar.readonly — listar as suas agendas para você escolher o destino dos lembretes.

4. Onde os dados ficam

A autorização do Google (token de acesso) é armazenada apenas no seu dispositivo, no armazenamento local do navegador. O aplicativo não envia esse token nem dados da sua agenda para nenhum servidor nosso — a comunicação de criação de eventos ocorre diretamente entre o seu navegador e o Google.

Os dados operacionais do aplicativo (anotações, tarefas, etc.) são armazenados em um banco de dados (Supabase) com acesso restrito ao seu grupo de trabalho, exclusivamente para o funcionamento do aplicativo.

5. Como usamos os dados

Os dados são usados somente para fornecer as funcionalidades do aplicativo. Não vendemos dados, não usamos para publicidade e não compartilhamos com terceiros, exceto quando estritamente necessário para operar o serviço (ex.: a própria API do Google, para criar o evento que você solicitou).

6. Uso limitado (Google API Services User Data Policy)

O uso e a transferência, pelo Meli Daily Assistant, de informações recebidas das APIs do Google obedecem à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

7. Como revogar o acesso

Você pode desconectar a qualquer momento:

  • No aplicativo: Configurações → Google Agenda (ou limpando os dados do site no navegador);
  • Na sua conta Google: myaccount.google.com/permissions → remover o acesso do "Meli Daily".

Ao revogar, novos lembretes deixam de ser criados. Eventos já criados permanecem na sua agenda até que você os remova.

8. Retenção

O token de autorização permanece apenas no seu dispositivo e é removido ao desconectar, ao limpar os dados do navegador ou quando expira.

9. Menores de idade

O aplicativo é destinado a colaboradores no contexto de trabalho e não se dirige a menores de idade.

10. Alterações nesta política

Podemos atualizar esta política. A data de "última atualização" no topo indica a versão vigente.
